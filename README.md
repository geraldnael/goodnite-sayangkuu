# 🌙 Selamat Bobo, Sayang

Aplikasi web romantis dengan langit malam berbintang, pesan cinta, dan backsound lagu — bisa dibuka di HP siapa saja lewat GitHub Pages.

---

## 📁 Struktur Folder

```
goodnight-app/
├── index.html
├── style.css
├── app.js
├── README.md
└── music/
    └── mereka.mp3   ← taruh file lagu kamu di sini
```

---

## 🚀 Cara Upload ke GitHub Pages

### Langkah 1 — Siapkan file lagu
Salin file lagu kamu ke folder **`music/`** dan **ganti namanya menjadi `mereka.mp3`**

### Langkah 2 — Buat repository di GitHub
1. Buka github.com → login → klik **New repository**
2. Nama repo: `goodnight-sayang` (atau bebas)
3. Pilih **Public** → klik **Create repository**

### Langkah 3 — Upload semua file
1. Klik **uploading an existing file**
2. Drag & drop semua file + folder `music/`
3. Klik **Commit changes**

### Langkah 4 — Aktifkan GitHub Pages
1. Klik tab **Settings** → **Pages** (sidebar kiri)
2. Source: **Deploy from a branch** → branch **main** → folder **/ (root)**
3. Klik **Save**

### Langkah 5 — Kirim linknya ke pacar 💕
Tunggu 1-2 menit, link kamu:
```
https://USERNAME.github.io/goodnight-sayang/
```

---

## ⚠️ Catatan
- File lagu **harus bernama `mereka.mp3`** (huruf kecil)
- GitHub Pages gratis, butuh akun GitHub
- File mp3 max ~25MB bisa upload langsung via web GitHub
